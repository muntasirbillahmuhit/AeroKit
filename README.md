# AeroKit — Modern React Utility Toolkit

AeroKit is a fast, offline-ready, privacy-first mobile & desktop utility suite rewritten from the ground up in **React 19**, **TypeScript**, and **Vite**.

## ✨ Features & Included Utilities

AeroKit brings 75+ precision tools organized into 13 dedicated categories:

- **Calculator**: Standard calculator with live evaluation and memory, Scientific calculator (DEG/RAD, trigonometry, logarithms, powers, factorials), Percentage calculator, and Date & Age interval calculator.
- **Finance & Money**: Expenses tracker with balance summary & transaction log, Multi-currency converter with exchange rate calculator, Loan & EMI installment estimator, Discount & sale price calculator, and Tip & bill splitter.
- **Converter**: Length, Weight & Mass, Temperature, Speed, Digital Storage, Area, Volume & Capacity, and Time Duration converters with instantaneous bidirectional conversion and persistent history.
- **QR & Barcode**: Built-in pure ISO/IEC 18004 QR encoder (generating SVG/PNG data URLs for Text, URLs, Wi-Fi networks, and vCard contacts) and Camera/Image scanner.
- **Image Tools**: Image compressor with quality slider, image resizer with aspect lock, color picker & eyedropper, Base64 encoder, format converter (JPEG, PNG, WebP), crop inspector, EXIF inspector, and SVG optimizer.
- **Internet & Network**: Internet speed tester with animated live speedometer gauge, IP address lookup with geo metadata, ping latency probe, and DNS record inspector.
- **Text Utilities**: Text case converter, live word & character counter with reading time, Lorem Ipsum generator, URL encoder/decoder, Base64 text encoder, URL slug generator, line cleaner, and text diff comparator.
- **Developer Tools**: JSON formatter & validator, UUID v4 generator, Web Crypto hash generator (SHA-1, SHA-256, SHA-512), JWT token inspector, Regex tester with live match highlights, HTML entity encoder, and Unix epoch timestamp converter.
- **Security & Privacy**: Cryptographically secure password generator, password entropy strength analyzer, secret token generator, Diceware passphrase generator, and browser privacy inspector.
- **Device Info**: Hardware overview, battery diagnostics, screen & viewport metrics, CPU cores & concurrency, and storage quota inspector.
- **Date & Time**: Animated analog clock, digital world clock, timezone converter, interactive monthly calendar, precision stopwatch with lap history, countdown timer with presets, Pomodoro focus timer, and tally counter.
- **Measurement**: Screen-calibrated ruler, digital protractor, spirit bubble level with accelerometer/manual tilt, physics pendulum simulation, and sound level decibel meter.
- **Lab & Sandbox**: Live HTML/CSS/JS sandbox, C code runner simulator, and Python script playground.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Production build
npm run build
```

## 🛡️ Privacy & Performance

- **Zero External Telemetry**: 100% of calculations, image processing, hashes, and conversions run locally on your device.
- **Mobile First Design**: Includes both phone mockup framing for desktop view and full-screen responsive view for mobile screens.
- **Dark & Light Mode**: Seamless dark/light theme switching with custom CSS variables and glassmorphism styling.
