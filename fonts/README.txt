এই ফোল্ডারে Manrope-Variable.woff2 ফাইলটি রাখুন।

ডাউনলোড (যেকোনো একটি):
1) https://fontsource.org/fonts/manrope  -> Download -> "manrope-latin-wght-normal.woff2" নিয়ে নাম বদলে Manrope-Variable.woff2 করুন
2) npm install @fontsource-variable/manrope  -> node_modules/@fontsource-variable/manrope/files/manrope-latin-wght-normal.woff2 কপি করুন

ফাইল না থাকলে অ্যাপ সিস্টেম ফন্টে চলবে, ভাঙবে না।
